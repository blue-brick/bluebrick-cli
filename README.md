# bluebrick

Blue Brick CLI. Scaffold a new project in seconds.

```bash
npx bluebrick create my-app
```

Pick a stack, get a working project with admin login, custom error pages and Tailwind already set up.

## Usage

```bash
bluebrick create [name] [options]
```

| Option | Description |
| --- | --- |
| `-t, --template <stack>` | `node` or `python` |
| `--no-install` | skip installing dependencies |
| `--no-git` | skip `git init` |

## Templates

- `node`: Express + EJS + Tailwind
- `python`: coming soon
